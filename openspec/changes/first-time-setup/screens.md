# Screens

The welcome screen, the wizard steps and the version card are being drawn in
ConductionNL/design-system on branch `design/thematiq-apps-menu-walkthrough`. When that pull request is
open, its board ids and links replace this note. They are canon: where this change and a board differ,
the change follows the board.

Existing boards the wizard reuses parts of:

- TqTheming https://identity.conduction.nl/screens/board?id=thematiq/TqTheming (the settings page the version card joins)
- TqTokenSet https://identity.conduction.nl/screens/board?id=thematiq/TqTokenSet (the set list and the licence block)
- TqThemingBijwerken https://identity.conduction.nl/screens/board?id=thematiq/TqThemingBijwerken (what applying to Nextcloud's theming changes)
- AppMenuConfiguratie https://identity.conduction.nl/screens/board?id=werkplek/AppMenuConfiguratie&ds=zuiddrecht (the menu defaults and grid preview)

The setup wizards of the other apps (DqInstellen, DqInstellenKlaar, PqInstellen) show the shared
`CnSetupWizard` look.
