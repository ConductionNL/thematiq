# zuiddrecht-table-header-board-palette Delta

## ADDED Requirements

### Requirement: Zuiddrecht's table header follows the workplace boards

The Zuiddrecht set SHALL draw a table's header row on #FAFBFC with its muted text colour at weight 600, and the muted
colour SHALL reach 4.5:1 on the header, a white row and the row hover, in the light and the generated dark variant.

#### Scenario: DqZaken

- **GIVEN** the cases index under the Zuiddrecht set
- **THEN** the header labels are #5E6168 at 600 on #FAFBFC
- **AND** a cell's muted line is #5E6168, not the body ink
