## Requirements
### Requirement: Self-Hosted Marianne Font Files

The app MUST bundle the Marianne `woff2` font files from `@gouvfr/dsfr@1.15.1`
(`dist/fonts/Marianne-*.woff2`, Etalab Open Licence 2.0) under
`css/systems/lasuite/fonts/marianne/`, self-hosted, covering the weights DSFR ships (Light,
Regular, Medium, Bold, plus their italics where available). The files MUST be materialised from
the DSFR package — either committed with a documented provenance comment, or generated by a
build script consuming `@gouvfr/dsfr` as a **devDependency** (mirroring `scripts/build-icons.js`
for the nc-vue icon packs) — with no runtime PHP or JS dependency on the package. The
authoritative set is what DSFR 1.15.1 ships; the count MUST NOT be hardcoded in application
code. The font layer that references them (`css/systems/lasuite/marianne.css`) MUST use
app-relative `url()` only — no `http://` or `https://` scheme — so no external request is made
and the assets are served CSP-clean from the app directory.

#### Scenario: Marianne woff2 files are bundled and self-hosted
@e2e exclude static asset invariant — PHPUnit inspects the marianne font directory and the stylesheet's url() references

- GIVEN the shipped app package
- WHEN `css/systems/lasuite/fonts/marianne/` is inspected
- THEN it MUST contain the DSFR Marianne `woff2` files (Light, Regular, Medium, Bold + italics
  where DSFR ships them)
- AND every `url()` in `css/systems/lasuite/marianne.css` MUST resolve to one of those files
  with an app-relative path
- AND no `url()` in that stylesheet MUST use an `http://` or `https://` scheme

#### Scenario: DSFR is a build-only dependency
@e2e exclude static dependency invariant — checked against package.json and runtime source

- GIVEN `package.json`
- WHEN `@gouvfr/dsfr` is located
- THEN it MUST appear under `devDependencies` (build-only)
- AND no runtime PHP or JS module MUST import or require `@gouvfr/dsfr`

### Requirement: Marianne Activation Requires an Admin Acknowledgement Gate

Marianne MUST be inert by default. The app MUST expose an app config flag
`nldesign` / `marianne_enabled` that defaults to `'0'`. `CssInjectionService` MUST emit the
`systems/lasuite/marianne` stylesheet (the real self-hosted `@font-face Marianne` declarations)
**only** when the active design system is `lasuite` AND `marianne_enabled === '1'`. While the
flag is `'0'` — or the active design system is not `lasuite` — the app MUST NOT emit any
`@font-face` `url()` source for Marianne, so the browser fetches no Marianne byte and the
`--lasuite-font-family: Marianne, Inter, sans-serif` stack renders **Inter**. The flag MUST be
settable only by an admin (the settings endpoint that writes it MUST carry
`#[AuthorizedAdminSetting(...)]`), and enabling it constitutes the operator's affirmation that
their organisation is a French State agency (see the user-agreement requirement below).

#### Scenario: Default off — Marianne never loads
@e2e Playwright verifies no Marianne request and Inter rendering with the gate off

- GIVEN the `lasuite` token set is active AND `marianne_enabled` is `'0'` (the default)
- WHEN a themed page renders
- THEN `CssInjectionService` MUST NOT emit `systems/lasuite/marianne`
- AND no HTTP request for any `Marianne-*.woff2` MUST occur
- AND the computed `font-family` on body text MUST resolve to Inter

#### Scenario: Enabled — Marianne self-hosts and renders
@e2e Playwright verifies the app-relative Marianne request and Marianne rendering with the gate on

- GIVEN the `lasuite` token set is active AND an admin has set `marianne_enabled` to `'1'`
- WHEN a themed page renders
- THEN `CssInjectionService` MUST emit `systems/lasuite/marianne` after the base
  `systems/lasuite/fonts` layer
- AND the browser MUST load the `Marianne-*.woff2` files from the app's own directory
  (HTTP 200, app-relative URL, no external host)
- AND the computed `font-family` on body text MUST resolve to Marianne

#### Scenario: Gate is admin-only
@e2e exclude authorization invariant — PHPUnit/route inspection asserts the endpoint's auth posture

- GIVEN the endpoint that writes `marianne_enabled`
- WHEN its route registration and controller attributes are read
- THEN it MUST declare `#[AuthorizedAdminSetting(...)]` (admin-only)
- AND a non-admin request to set the flag MUST be rejected

#### Scenario: Reverting the gate returns to Inter
@e2e Playwright toggles the flag off and re-checks

- GIVEN `marianne_enabled` was `'1'` and Marianne was rendering
- WHEN an admin unticks the acknowledgement (flag set to `'0'`)
- THEN the next render MUST NOT emit `systems/lasuite/marianne`
- AND body text MUST render in Inter again

### Requirement: Marianne Licence and User Agreement Artifacts

The repository MUST carry, as checked-in files, the licence and the operator agreement for
Marianne. `MARIANNE-LICENCE.md` MUST reproduce the Etalab Open Licence 2.0 terms **and** the
Marianne restriction (*"réservée aux administrations de l'État"* — reserved for French State
administrations) **verbatim**, together with the source URL of the DSFR package / official
system-de-design site and the Etalab licence URL. `AGREEMENT-MARIANNE.md` MUST state that
enabling Marianne is permitted ONLY when the serving organisation is a French State agency, that
the operator affirms this eligibility by enabling the acknowledgement gate, and that Conduction
bundles Marianne solely for that lawful use. `LICENSES/etalab-2.0.txt` MUST carry the full
Etalab Open Licence 2.0 text under the `etalab-2.0` SPDX identifier — lower-case, because that
is the identifier the SPDX licence list actually carries and the only spelling `reuse lint`
accepts in `LICENSES/`. The `Etalab-2.0` spelling stays in `.license-overrides.json`, which is
a different gate: it matches the licence string the dependency SBOM reports for `@gouvfr/dsfr`.

#### Scenario: Legal artifacts are present and cite the source
@e2e exclude documentation invariant — PHPUnit asserts file existence and required phrases

- GIVEN the shipped app package
- WHEN the repository root is inspected
- THEN `MARIANNE-LICENCE.md`, `AGREEMENT-MARIANNE.md`, and `LICENSES/etalab-2.0.txt` MUST all
  exist
- AND `MARIANNE-LICENCE.md` MUST contain the Marianne restriction wording and a source URL
- AND `AGREEMENT-MARIANNE.md` MUST state the French-State-agency eligibility condition

### Requirement: Marianne woff2 Files Carry SPDX / REUSE Attribution

Every bundled Marianne `woff2` file MUST travel with its `Etalab-2.0` licence notice, in the
same way `OFL.txt` travels with the Inter files under `css/systems/lasuite/fonts/`.
`.license-overrides.json` MUST map the `css/systems/lasuite/fonts/marianne/*.woff2` paths to the
`Etalab-2.0` SPDX identifier so REUSE/SPDX tooling reports the correct licence for binary assets
that cannot carry an inline header.

#### Scenario: License-compliance tooling resolves Etalab-2.0 for the Marianne files
@e2e exclude static licensing invariant — PHPUnit / REUSE check reads .license-overrides.json and LICENSES/

- GIVEN `.license-overrides.json` and `LICENSES/`
- WHEN the Marianne `woff2` paths are resolved
- THEN each MUST map to the `Etalab-2.0` SPDX identifier
- AND `LICENSES/etalab-2.0.txt` MUST exist so the identifier resolves to licence text

### Requirement: Restriction Notice Is Unmissable at the Point of Selection

The restriction MUST be surfaced where an operator selects/enables Marianne — a visible notice
in the admin settings UI adjacent to the acknowledgement control, and a section in `README.md`
and the relevant `docs/` page. The notice MUST state that Marianne is the official typeface of
the French State, reserved for French State administrations, that it is off by default, and that
Inter is used otherwise. The admin-UI notice MUST be translatable: an English source key MUST
exist in `l10n/en.json`, with corresponding translations in `l10n/nl.json` (Dutch) and
`l10n/fr.json` (French).

#### Scenario: Notice shows beside the acknowledgement control
@e2e Playwright asserts the notice renders in admin settings when lasuite is selected

- GIVEN the `lasuite` token set is the selected design system in admin settings
- WHEN the settings page renders
- THEN the Marianne acknowledgement control MUST be shown
- AND a visible restriction notice MUST appear adjacent to it, stating the French-State-agency
  restriction and that Inter is the default

#### Scenario: Notice string is translated
@e2e exclude i18n inventory invariant — PHPUnit asserts the key exists in en/nl/fr l10n files

- GIVEN the English Marianne restriction notice key in `l10n/en.json`
- WHEN `l10n/nl.json` and `l10n/fr.json` are read
- THEN each MUST contain a translation for that key
- AND the Dutch and French values MUST NOT be the untranslated English source string
