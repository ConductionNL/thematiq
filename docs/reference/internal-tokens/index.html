Component variables

Nextcloud 34.0.0.12 and @conduction/nextcloud-vue 2.57.1 style their components with variables of their own, below the theme vocabulary. Each one below has a token a set or an admin override can give a value. A token nobody sets changes nothing.

Reaches says how a value gets there:

  • every reader: components only read the variable, so one value on the page reaches them all.
  • its component: the component declares the variable itself, so the value is written onto that element.

An internal token applies in light and dark alike. Give it a value in the dark file to differ in dark.
