Nextcloud variables and thematiq

This page lists every CSS custom property that Nextcloud 34.0.0.12 and @conduction/nextcloud-vue 2.57.1 declare or read, and what thematiq does with each one.

  • mapped: a house style sets it.
  • settable: a house style can set it; unset, Nextcloud keeps its own value.
  • excluded: thematiq leaves it alone, for the reason given.
