# Architecture decision records

These records restate decisions this repository already made and wrote down in its OpenSpec design files. Each record names its source. New decisions are still written in the `design.md` of an OpenSpec change under `openspec/changes/`.

| Number | Decision | Status |
| --- | --- | --- |
| [0001](0001-design-systems-as-declared-stylesheet-bundles.md) | Design systems are declared stylesheet bundles | Accepted |
| [0002](0002-token-sets-are-data.md) | Token sets are data, discovered from files and a manifest | Accepted |
| [0003](0003-one-nldesign-token-namespace-with-defaults-file.md) | One token namespace with a separate defaults file | Accepted |
| [0004](0004-upstream-token-sync-through-reviewed-pull-requests.md) | Upstream tokens are synced in Node.js through reviewed pull requests | Accepted |
| [0005](0005-inject-styles-on-template-render-events.md) | Styles are injected on template render events, not at app boot | Accepted |
| [0006](0006-runtime-files-live-in-app-data.md) | Files written at runtime live in app data, not the app directory | Accepted |
| [0007](0007-icons-materialised-at-build-time.md) | Icon packs are materialised as SVG files at build time | Accepted |
