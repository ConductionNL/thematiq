## What

The id-level nldesign link rule in `css/systems/nldesign/element-overrides.css` (`a:not(#header a)…` with `color: … !important`) now skips `.cn-look-board .cn-index-page__page-tab`, the same way it already skips the board card title.

## Why

nextcloud-vue's CnIndexPage draws an index page's sibling lists as folder tabs (`.cn-index-page__page-tab`, links). The board draws them as tabs in the main text colour. Because the link rule wins at id level, they were drawn in the link colour (DqContracten: rgb(54, 105, 165) where the board has rgb(27, 28, 29), COMPDIFF r24). nextcloud-vue `fix/board-index-page-tabs-type` (10f175ad9b) paints the board-look tab `color: var(--color-main-text) !important`; this PR lets that win. The tab is only skipped under the board look: outside it the link rule still applies.
